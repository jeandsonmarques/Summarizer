# Summarizer Branding and Trademark Policy

This document covers the project name, logo, icons, visual identity, and other brand assets used to identify the original Summarizer project.

## Scope

- `Summarizer`, the project logo, icons, and related visual identity elements belong to the original author/project to the extent recognized by law.
- The GPL license for the code does not grant any trademark, branding, or trade-dress rights.
- Nothing in this document changes the rights granted by the GPL for the software code itself.

## Forks and modified versions

- Forks and modified distributions must use a different name if there is any realistic chance of confusion with the original project.
- Forks should remove or replace the original logo, icons, and other visual identity elements unless the original author has given separate written permission.
- Forks must clearly state that they are modified versions and are not official releases of Summarizer.
- Forks may say they are "based on Summarizer" for attribution only, provided that the wording does not imply sponsorship, approval, or official status.

## Allowed attribution

- It is acceptable to acknowledge the original project in a factual way, such as "based on Summarizer" or "derived from Summarizer", when that is accurate.
- Attribution must not be presented in a way that confuses users about the origin, maintenance, or endorsement of the fork.

## Relationship to the license

- Code remains governed by `GPL-3.0-or-later`.
- Brand and trademark usage are separate from the code license and may be restricted even when code redistribution is allowed.
- Modified versions must keep copyright notices, keep license notices intact, and clearly identify their changes.
